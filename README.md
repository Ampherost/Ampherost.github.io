# My Developer Portfolio

Welcome to my personal developer portfolio, built with [Next.js](https://nextjs.org), styled using [Tailwind CSS](https://tailwindcss.com), and deployed with [Vercel](https://vercel.com). This site showcases my projects, skills, and interests as an aspiring software engineer.

## Live Site

Check it out live: [portfolio-russell-lys-projects.vercel.app](https://portfolio-russell-lys-projects.vercel.app)

## Tech Stack

- **Frontend Framework:** [Next.js](https://nextjs.org) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com)
- **Hosting:** [Vercel](https://vercel.com)
